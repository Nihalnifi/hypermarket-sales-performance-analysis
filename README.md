# Hypermarket Sales Performance Analysis

## Project Overview

This project focuses on analyzing hypermarket sales data using MySQL to understand sales performance, customer activity, product performance, category trends, promotions, and discount impact.

The analysis uses SQL techniques to answer business-related questions and identify patterns that can support better sales and business decisions.

## Tools Used

- MySQL
- MySQL Workbench
- SQL

## Dataset

The dataset contains more than:

- 77K transactions
- 2.5K customers
- 42K+ products

The data includes information related to sales transactions, customers, products, categories, promotions, and discounts.

## Analysis Performed

The project includes analysis of:

- Overall sales performance
- Category-wise sales
- Top-performing categories
- Customer activity
- Product performance
- Monthly sales trends
- Month-over-Month (MoM) sales
- Promotions and discounts
- Revenue patterns
- Running sales totals
- Category rankings

## SQL Concepts Used

The project demonstrates the use of:

- SELECT and WHERE
- GROUP BY and HAVING
- Aggregate Functions
- JOINs
- CASE WHEN
- Common Table Expressions (CTEs)
- Subqueries
- Window Functions
- Ranking Functions
- Running Totals
- Date Functions
- Month-over-Month Analysis

## Key Business Questions

Some of the questions explored in this project include:

- Which categories generate the highest sales?
- Which categories perform best based on ranking?
- How do sales change month over month?
- What are the running sales totals over time?
- How do promotions affect sales?
- What is the impact of discounts on revenue?
- Which products and categories contribute most to sales performance?



## Objective

The main objective of this project is to apply SQL skills to a realistic retail dataset and generate meaningful business insights from sales data.
